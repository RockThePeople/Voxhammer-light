# 3. R10a 조건 렌더 축소 — 사용 시점 1개, 마스크는 depth 만 (a5000)

- 요구사항: [REQUIREMENTS.md](../REQUIREMENTS.md) 4.4 「3. R10a」, 6장 구간 1. 0번 A-5b(실행 간 차이), STATE 결정 「R10a 기준」.
- 선행: 0번 승인. 순서: 2 R4 다음. **R4 와 같은 렌더 입력(정점색 GLB) 문제를 공유**하므로 R4 의 R-2 결과를 먼저 본다.
- 담당: **a5000**. 브랜치 `item/03-R10a-a5000`. 보고서 `docs/reports/03-R10a.md`.
- 결과 유형: **동일(시드 고정 후).** 토글 `VHL_R10A=1`(기본 꺼짐: 포크 렌더러 5시점 × 2).
- 하지 않는 것: 렌더러 교체(15 R10, 3순위), 해상도·샘플 수·환경맵 변경, 포크 수정.

## T-1 구현

- `editcore/render.py` 에 새 렌더 함수를 둔다(포크 `utils/render_rgb_and_mask.py` 는 고치지 않는다. 포크와 같은 `bpyrenderer` 함수를 쓰는 새 코드, 출처 주석).
  - 원본 GLB: **요청 시점 1개만** RGB(PNG, 1024², film transparent) + depth. 카메라는 포크와 같은 식(`get_camera_positions_on_sphere(center 0, radius 1.8, elevations [15], azimuths [a − 90 for a in 90, 45, 0, 315, 270])`)에서 그 시점 행렬 하나를 쓴다.
  - 마스크 GLB: 같은 시점 **depth 만**(색 출력 끔).
  - 2D 마스크: 포크 정의 그대로 `원본 depth − 마스크 depth > 1e-4`, 배경 처리(`load_depth`)도 같게. RGBA → 흰 배경 합성 등 후처리 순서도 포크와 같게.
  - 장면 설정은 포크와 같게: CYCLES, smooth, clear_normal_map, 투명도 끔, opaque, 환경맵 `brown_photostudio_02_1k.exr`.
  - **Cycles 시드 고정**(`scene.cycles.seed = 0`, animated seed 끔). 기본값과 같은지 코드로 확인해 적는다.
  - EXR 읽기는 0번의 bpy 경유 방식(`reference/run_condition_render.py` `_Cv2ExrViaBpy`)과 같은 식으로 하되, editcore 는 그 우회에 의존하지 않는다(STATE 결정: EXR 우회는 새 패키지가 의존하지 않는다) — depth 는 bpy 로 직접 읽는다.
- Blender 프로세스 기동·장면 적재 비용을 따로 잰다(렌더 2회가 같은 프로세스·같은 장면 초기화를 공유할 수 있으면 그렇게 하고, 결과가 같음을 확인한다).

## T-2 예상 (실행 전에 적는다)

- 0번 구간 1 = 26.1 s = 원본 5시점 14.3 + 마스크 5시점 8.7 + 2D 후처리 3.0(실측). 시점당 렌더가 선형이고 기동 비용이 렌더 호출마다 고정이라 보면 1시점 + depth 만으로 약 6–10 s(추론). 기동 비용 비중을 측정으로 가른다.

## T-3 검증

- 비교 기준: 포크 렌더러(수정 없음, 0번 래퍼)의 같은 시점 출력. STATE 결정에 따라 **2D 마스크는 비트 동일, RGB 는 채널 차 ≤ 1** 이면 동일로 본다(0번 A-5b 실행 간 차이). 넘으면 픽셀 수·위치·최대값을 적고 멈춘다.
- 대상: 트랙 A 6건(편집 시점, 동결 조건 렌더와 비교) + 트랙 B 8건(F-3 의 포크 조건 렌더, 같은 편집 시점) + moto-b 2건.
- 시간: 구간 1 을 토글 켬/끔 각 3회(평균±표준편차), 세부(기동·장면 적재·원본 RGB+depth·마스크 depth·후처리).
- 회차 간: 토글 켬 3회의 RGB·마스크 비트 동일 여부(시드 고정 효과).
- R4 이후 입력(정점색 GLB)으로도 1건 이상 돌려, R4 R-2 결과와 같은 판정인지 적는다.
