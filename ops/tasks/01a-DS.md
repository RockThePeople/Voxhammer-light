- 근거: 정오표 E16(고객사 회신 2026-10-25). 순서표 밖 보조 항목, **1번 E2a 다음·2번 R4 앞**.
- 담당: **a5000**. 브랜치 `item/01a-DS-a5000`(main 에서 분기). 보고서 `docs/reports/01a-DS.md`.
- 목적: 검증 전용. Stage 2 실행 간 차이(0-1 보고 5a: TRELLIS `SparseDownsample.forward` 의 `torch.scatter_reduce(..., reduce='mean')`, `trellis/modules/sparse/spatial.py:36`)를 없애, 이후 "동일" 항목(R4·R8a·R12·R7g 등)에서 Stage 2 를 **비트 비교**할 수 있게 한다.
- 토글: `VHL_DS_DETERMINISTIC=1` 일 때만 켜진다. **운영 기본값 꺼짐**(서비스·CLI 기본 경로는 그대로 비결정 원본 연산).
- 하지 않는 것: 다른 scatter·atomic 연산 교체(이번 측정에서 Stage 2 의 첫 차이 지점은 이 모듈 하나), 운영 기본값 변경, 성능 개선 주장.

## D-1 구현

- 결정적 대체 연산: 같은 입력에서 항상 같은 비트를 내는 segment mean. 예: 목표 인덱스로 안정 정렬 → 정렬된 순서로 구간 합(`torch.segment_reduce` 또는 cumsum 차분 등 누적 순서가 고정된 방법) → 개수로 나눔. 원자적 덧셈을 쓰지 않는다.
  - `torch.use_deterministic_algorithms(True)` 로 해결되면 그것도 후보지만, 전역 설정이 다른 연산에 영향을 주면 안 되므로 이 모듈 안에서만 적용되게 한다. 쓴 방법과 근거를 보고서에 적는다.
  - 원본과 수학적으로 같은 평균이어야 한다(dtype 유지). 원본 대비 수치 차이(max·mean |Δ|, 무작위 입력)를 CPU·GPU 단위 테스트로 적는다.
- 적용 방법:
  - editcore: 명시적 클래스/함수로 `SparseDownsample` 의 forward 를 대체하는 래퍼를 두고, 토글이 켜졌을 때만 Stage 2 flow 모델의 해당 모듈에 적용한다(`MethodType` 금지 규칙 준수 — 모듈 교체 또는 명시적 서브클래스).
  - 포크: **파일은 고치지 않는다.** 검증 스크립트(`tests/gpu/`)에서 실행 시 TRELLIS 모듈의 forward 를 같은 결정적 구현으로 바꿔 끼운다(E16 검증 한정 예외). 포크 결과 저장 경로·시드 처리는 0-1 종단 비교와 같게.
- 로그: 토글 상태, 교체된 모듈 이름·개수, 결정적 연산 호출 횟수(경로가 실제로 돌았다는 증거).

## D-2 예상 (실행 전에 먼저 적는다)

- 켰을 때: 같은 코드 2회(포크–포크, 이식–이식)와 이식–포크의 Stage 2 잠재 캐시 25/25·K/V 4,800/4,800·편집 셀 feats 비트 동일.
- 결과 분포: 원자적 덧셈과 고정 순서 합의 차이는 반올림 수준이라, 켠 결과는 꺼진 결과의 실행 간 분포 안(E14 기준 통과).
- 시간: Stage 2 구간에 정렬 비용이 더해진다. 크기를 적는다(운영에는 쓰지 않으므로 판정 대상 아님).

## D-3 검증

1. 단위: 무작위 sparse 입력(여러 크기·채널)에서 결정적 구현 2회 비트 동일, 원본 대비 |Δ| 기록.
2. 모듈 추적: 0-1 의 `tests/gpu/find_stage2_nondeterminism.py` 를 토글 켠 상태로 다시 돌려 558개 모듈이 2회 모두 비트 동일인지. 아니면 다음으로 갈리는 모듈을 적는다.
3. 종단 (14건 + moto-b 2건, seed 0, 토글 켬):
   - 포크–포크 2회, 이식–이식 2회, 이식–포크 3쌍 → coords·보존 셀·편집 셀 feats·Stage 2 캐시 다이제스트 **비트 동일 여부**.
   - 분포 비교: 토글 켠 결과(이식) vs 토글 끈 기준 F-5 r1–r3. 켬–끔 쌍과 끔–끔 쌍으로 E14 세 조건(max·mean 각각)과 E15(쌍별 mean ≤ 3.2e-3)를 계산한다.
4. 시간: 구간 6(Stage 2) 켬/끔 3회 평균. 테스트(CPU·conformance 53/53·서버 360).
