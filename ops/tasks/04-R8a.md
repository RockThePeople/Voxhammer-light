- 결과 유형: **동일.** 토글: 워커 자체가 새 진입점(`services/a5000_edit/`), 기존 CLI 경로는 그대로.

## A. a5000 — 상주 워커

### A-1 프로세스
- 시작 시 1회 로드: 두 flow, SS 인코더·디코더, SLat mesh 디코더(R4 경로), 조건 이미지 인코더(DINOv2). 로드 시간 기록.
- 단일 큐(GPU 직렬), 큐 대기 시간 기록. 포트 8082, 3090 → A5000 한 방향(E4·A5).
- 요청마다 `torch.inference_mode()`. 포크 `run_edit` 끝의 `set_grad_enabled(True)` 해당 동작은 넣지 않는다.
- 편집이 끝나면 K/V 캐시·중간 텐서를 해제한다. 요청 후 RSS·VRAM 이 1회차 이전 수준으로 돌아오는지 기록.
- 같은 자산은 판본 순서대로. 기준 판본이 다르면 409 `VERSION_CONFLICT`.

### A-2 엔드포인트 (규약 §3)
- `POST /v2/trellis/render`: R10a 렌더러로 요청 시점 1개 원본 렌더 + 2D 마스크, `render_id` 기록 24 h(`RUNS_DIR`, 재기동 유지), 해시 반환.
- `POST /v2/trellis/edit`(multipart `meta` + `2d_render`·`2d_mask`·`2d_edit`): 렌더 해시·`base_version` 대조 → 편집(editcore, W34 입력 SLat = 직전 판본 `slat_tgt`) → R4 `.cbin` 청크 + R11 승계 → 판본 저장(R2 SLat 포함).
- 거절 사유 §3.3 전부(422·409·404·400) 를 테스트로 확인. 기존 `image` 필드는 받지 않는다.
- `GET /v2/trellis/jobs/<id>`, 청크 제공은 기존 응답 모양(chunks, to_version) 유지.

### A-3 검증
- 같은 입력으로 3회 연속 요청: 결과가 CLI 1회 실행과 동등(E14·E15, coords·보존 셀 비트 동일). 2·3회차 RSS·VRAM 복귀.
- 시간: 첫 요청 / 이후 요청의 구간 3–7, 로드 시간(시작 시 1회), 큐 대기. 14건 × 3회는 워커 경유로 한 번 돌려 CLI 결과와 비교한다.
- 서버·계약: conformance 53/53, ai-ar-v3 서버 360 passed, 워커 자체 테스트(GPU 없이 도는 계약 테스트 포함).

## B. rtx3090 — 오케스트레이터 (규약 §1)

- 3090 오케스트레이터(ai-ar-v3 `server/voxhammer.py`)에서 t2i 조건 생성(`render_rgba`) 부분만 ① A5000 render → ② 로컬 R9 인페인팅 워커 → ③ A5000 edit(multipart)로 바꾼다. `RENDER_UNKNOWN` 이면 ①부터 1회 재시도.
- 멱등 키에 `sha256(2d_edit)` 추가(§4 결정 3).
- **ai-ar-v3 반영(E4):** 계약 변경 제안(deltacontract 스키마·오케스트레이터·테스트) + 패치를 **ai-ar-v3 PR** 로 낸다. conformance 전부·서버 테스트 전부 통과. 병합은 고객사. Voxhammer-light 쪽 PR 본문에 그 PR 링크를 적는다.
- 착수 가능 범위: A5000 엔드포인트가 뜨기 전에는 규약대로 응답하는 모의 서버(테스트 전용)로 개발·테스트한다. 실제 종단 시험은 A5000 워커가 뜬 뒤.

## C. 종단 (두 장비)

- 3090 → A5000 8082 연결(방화벽은 고객사 관리자). 연결이 안 되면 그 사실과 시험 명령을 보고하고 `xfer/` 경로로 대체하지 않는다(R8a 는 실연결이 조건).
- 측정: ①·②·③ 각 구간, 장비 간 전송(이미지 3장·청크), 편집 1회 벽시계(3090 에서 본 값). 트랙 A 6건 × 3회.
- R9 기본값: 이 시험에서는 `VHL_R9=1` 로 켠다(R9 3D 기록, E6). 결과는 R9 보고에 따로 적는다.

## D. 예상 (실행 전에 적는다)

- 모델 로드 31.0 s 가 요청당 0 이 된다(첫 요청 제외). 구간 3–7 은 CLI 와 같다. 3090 기준 편집 1회 = 렌더(R10a) + 인페인팅(R9 약 26 s) + 편집 3–7 + 전송.
