## V-1 시나리오 페이지 `/scenario/<ID>` (14건 + moto-b 2건)

한 페이지에 아래를 위에서 아래로 둔다. 목록 페이지에 "시나리오" 탭을 추가해 16건을 썸네일로 보여 준다.

1. **머리말:** ID, 데이터셋·객체, 편집 프롬프트(트랙 A 인페인팅 프롬프트 / 트랙 B 데이터셋 프롬프트), 마스크 셀 수·지문, 편집 시점, E12 표시(A-C2·A-S1), 동결 해시 일부. 출처는 `scenarios/track_a.json`·`track_b.json`.
2. **조건 이미지:** 동결 `2d_render` | `2d_mask` | `2d_edit` 를 나란히, 그리고 `2d_render` 위에 `2d_mask` 를 반투명 빨강으로 겹친 그림. 이미지 크기 그대로(1024²) 볼 수 있게 클릭 확대.
3. **3D 비교(핵심):** 같은 화면에 3D 칸 여러 개, **카메라가 모두 연동**된다(한 칸을 돌리면 다 같이 돈다).
   - 칸 선택: 원본 / base(25) / c15(채택) / c12 / s1-12 / s2-12 / 이후 항목 결과. 회차 r1–r3 선택.
   - 카메라 버튼: "편집 시점", "3/4 시점", 포크 5시점(0–4). 포크 조건 렌더와 같은 정의(반지름 1.8, 고도 15°, 방위 [90,45,0,315,270] − 90, 원점 주시, 원근 화각은 포크·bpyrenderer 기본값과 같게).
   - 결과 GLB 와 원본 GLB 는 F-5·E2a 시트와 같은 정규화로 같은 좌표에 놓는다.
4. **복셀 겹치기(64³ 셀, 체크박스로 켜고 끔):**
   - 편집 마스크 셀(빨강 반투명 상자), halo 2 고리(주황 테두리).
   - 결과 vs 입력 SLat 점유 차이: **마스크 안 신규(초록), 마스크 밖 신규 = R_keep 신규(노랑), 소실(파랑)**. 셀 수를 범례에 숫자로.
   - 마스크 밖 신규는 26-이웃 연결 성분별로 고를 수 있게 하고, 성분마다 셀 수·마스크 ∪ halo 까지 거리(E2a §4a 와 같은 계산)를 표시한다. 9a 필터 대상(마스크 ∪ halo 와 접촉 없음)은 따로 표시.
   - 메시만 / 복셀만 / 둘 다 보기.
5. **수치 표:** 그 시나리오의 설정별 R_keep(소실·신규·편집량), 렌더 지표(트랙 B), DINO-I·CLIP-T, E19 판정(통과·초과 칸 강조), 구간 4–7 시간. 출처 JSON 경로와 sha256 을 표 아래에 적는다.

## V-2 정렬 정확성 (필수, 숫자로 확인)

"정확하게 보인다"의 근거를 숫자로 남긴다. 복셀 좌표(64³, SLat coords) → 화면 좌표 변환은 한 곳(서버 쪽 전처리 또는 `common.js` 한 함수)에서만 한다.
- **복셀–메시 정렬:** 16건 원본 GLB 에 대해, 원본 SLat 점유 셀 중심에서 (같은 변환을 건) 원본 메시 표면까지 거리를 계산해 1셀 이내 비율을 적는다. 목표 ≥ 95%. 미달이면 변환을 고치고 원인을 적는다.
- **카메라 정합:** 3건 이상(A-S1·B7·moto-b rider-head)에서 뷰어의 "편집 시점" 화면 캡처(headless Chrome)와 동결 `2d_render` 의 실루엣 IoU 를 적는다. 목표 ≥ 0.95(조명 차이는 무관, 실루엣만).
- **마스크 투영 정합:** 같은 3건에서 마스크 셀 겹치기를 편집 시점으로 투영한 실루엣과 동결 `2d_mask` 의 IoU.
- 화면 캡처(편집 시점·3/4 시점, 겹치기 켬)를 보고서에 붙인다: A-S1(마스크 밖 앞·뒤 두 성분이 보여야 한다), B7(c12 의 마스크 접촉 증가 3성분), A-M1(c15 의 떨어진 덩어리).

## V-5 청크 보기 (2026-10-26 추가, R4 이후)

Unity 는 보류이므로, 요구사항의 "바뀐 청크만 in-place 교체"를 웹에서 확인하는 대체 화면.
- R4 결과 칸에 "청크" 보기: 부모 청크 집합을 띄운 뒤 **변경 청크만 교체**해서 보여 준다(부모 GLB 를 통째로 바꾸지 않는다). 승계 청크는 회색 테두리, 변경 청크(부기)는 빨강, 점유 변경으로만 추가된 청크는 노랑, 제거 청크는 점선.
- 청크별 표: 키, 상태(승계·변경·제거), 면 수, 바이트, 승계 청크는 부모와 바이트 동일 여부(sha256).
- "교체 전 / 교체 후" 토글로 같은 카메라에서 바뀐 부분만 바뀌는지 본다.
