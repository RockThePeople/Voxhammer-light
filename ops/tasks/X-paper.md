## 0. 경로 정의 (고정)

| 이름 | 내용 | 구현 |
|---|---|---|
| **P0** 원저자 | 편집마다 GLB → 150시점 렌더 → 재등록(인코딩) → 25 스텝 편집 → `to_glb`. 인페인팅 bf16(A5000, offload) | `reference/run_reference.py --mode original`(포크 무수정, 0번 래퍼). `--reuse_render` 쓰지 않는다. 시드는 `--seed 0`(Stage 2 출발 잡음만 고정, 재등록 잡음은 그대로 둔다 — 이것이 P0 의 성질이다) |
| **P1** 우리 | 저장 SLat 재사용(W34) + editcore 15/15 + **R4(`.cbin`, R11 승계, 경계 스냅)**. 인페인팅은 실험이 정한 것(X2-C 는 INT4) | editcore CLI `VHL_R4=1`, seed 0 |

- **P1 출력 메시(chief 보정 1):** 논문 시간 수치에 R4(구간 7 −18.1 s)가 들어가므로 품질도 R4 출력으로 잰다. 단 R4 메시는 `to_glb` 가 지우던 가려진 내부 면이 남아 형상 지표(CD·F1·NC)가 불리하게 나올 수 있다(R4 3-8: B4 Chamfer). 그래서 **X0·X2-A 는 P1 을 두 가지로 모두 채점**한다: `P1-cbin`(R4 `.cbin` → GLB) 과 `P1-glb`(같은 slat_tgt 의 `to_glb`). 둘 다 저장 slat_tgt 재디코딩이라 편집을 다시 돌리지 않는다. 논문에 어느 쪽을 쓸지는 결과를 보고 사용자가 정한다. X3·X4·X2-C 는 `P1-cbin` 만.
- **정점색 GLB 렌더(chief 보정 2):** `.cbin` 에서 만든 정점색 GLB 는 재질이 없어 Blender 가 회색으로 그린다(R4 R-2). 모든 Blender 렌더 — 조건 렌더, Edit3D-Bench `render.py`, **P2 의 150시점 재등록 렌더** — 에 들어가기 전에 `editcore/render.py:vertex_color_render_glb` (iv) 보정을 거친다. P2 재등록에서 이것을 빠뜨리면 회색 렌더로 DINOv2 특징을 뽑게 되어 P2 결과가 무의미해진다. 첫 P2 실행에서 150시점 중 3장을 시트로 남겨 색이 나오는지 확인한다.

## 1. 채점 도구 `tools/paper_metrics.py` (먼저, CPU)

모든 실험이 같은 도구를 쓴다. 정의를 코드 상단 주석과 보고서에 그대로 적는다.

- **좌표 정렬:** 결과 메시(P0 `to_glb` 는 Y-up 회전, R4 `.cbin` 은 NORMALIZED)와 64³ 셀을 같은 좌표계로 맞춘다. T1 뷰어의 정렬 코드(복셀–메시 1셀 이내 ≥ 95% 검증됨)를 재사용하고, 실험마다 정렬 확인 값(1셀 이내 비율)을 적는다.
- **정규화(chief 보정 3):** 자산마다 **v0 메시의 bbox 로 정한 변환 하나**(중심 원점, 최대 변 1)를 그 자산의 모든 결과에 똑같이 적용한다. 결과 메시마다 따로 정규화하지 않는다 — 편집으로 bbox 가 바뀌면 보존 영역까지 움직여 보이기 때문이다.
- **표면 샘플:** 면적 비례 균일 100,000점, 법선 포함, 고정 RNG(seed 0).
- **보존 영역 점:** 점이 속한 64³ 셀이 `dilate_cells(편집 마스크 ∪ …, 2)`(E2) 밖인 점. X3 은 그 회차까지 누적 마스크.
- **CD:** 두 방향 평균 최근접 거리의 평균(양방향 합이 아니라 평균; 보고서에 식). **NC:** 최근접 점 쌍의 |법선 내적| 평균(양방향 평균). **F1@0.01:** 거리 ≤ 0.01 인 비율로 정밀도(결과→참조)·재현율(참조→결과)의 조화평균.
- **점유:** R_keep 안 64³ 점유 IoU, 소실·신규 셀(E18 정의 그대로).
- **PSNR·SSIM·LPIPS(M):** Edit3D-Bench `render.py` 16시점. 제외 마스크 = 편집 영역 셀(∪ halo 2)을 같은 카메라로 투영한 실루엣(셀을 정육면체로 래스터). 비교 화소 = (참조 알파 ∪ 결과 알파) − 제외 마스크. 배경만인 화소는 넣지 않는다(배경이 PSNR 을 부풀리지 않게).
- **DINO-I:** 편집 시점 결과 렌더 vs 그 편집의 2d_edit. **CLIP-T:** 편집 시점 결과 렌더 vs 편집 프롬프트. 기존 `tools/e2a_metrics.py` 의 모델·전처리를 그대로 쓴다.
- **FID·FVD:** X2-B 에서만. FVD 는 16시점 회전 시퀀스를 영상으로 본다.
- 단위 테스트(CPU): 같은 메시끼리 CD 0·NC 1·F1 1, 알려진 평행이동에서 CD 값, 실루엣 투영이 R4 3-5 의 2D 마스크와 같은 시점에서 IoU ≥ 0.9.

- **비교 기준(chief 보정 6, 2026-10-26 13:3x, X3·X4):** 각 경로는 **자기 출발점** 과 비교한다 — P0 는 생성 텍스처 GLB(A_origin), P1·P2 는 A_origin SLat 을 R4 로 디코딩한 `.cbin`(→ GLB). 주 결과는 이 기준의 회차별 값(편집을 반복할수록 출발점에서 얼마나 멀어지는가)이다. 함께 **공통 기준(생성 텍스처 GLB) 대비 절대값**도 모든 경로에 적어, 0회차 출발점 차이(형식 차이: 정점색·내부 면·단순화 유무)를 숨기지 않는다. 0회차(편집 전) 값도 표에 넣는다.
- **해석 주의(보고서에 적을 것):** P1 은 R11 승계로 보존 청크가 출발점과 바이트 동일이라, P1 의 보존 손실은 주로 마스크 밖 신규 셀(15 스텝 Stage 1)과 경계 스냅 몫이다. P1–P2 차이 = 재등록 효과, P0–P2 차이 = 그 밖의 경로 차이(25 대 15 스텝, 출력 형식, 인페인팅). 회차별 마스크 밖 신규 셀 수를 경로마다 따로 적는다.
