# 4L. 인페인팅 → 편집 경로 연결 (a5000 + rtx3090) — 순서표 보류 중 최우선

- 지시: 사용자 2026-10-26 10:18. **순서표(3 R10a 이후)를 보류하고 이 항목을 먼저 한다.** 목적은 논문용 실험이 돌아가는 종단 경로(3090 오케스트레이터 → A5000 렌더 → 3090 INT4 인페인팅 → A5000 편집 → `.cbin`)를 빨리 확보하는 것이다. 실험 목록은 사용자가 따로 준다.
- 범위 = 4번 R8a 의 A5000 워커([04-R8a.md](04-R8a.md) A절) + 5번 R9 의 R-7 종단([05-R9.md](05-R9.md) R-7). 두 지시서의 규칙은 그대로 쓰고, 아래만 바꾼다.
- 우선순위: 빠른 프로토타입. 결과에 영향 있는 규칙(보존 동작·coords·보존 셀·R11 승계·토글 기본 꺼짐·해시 대조)은 그대로 지킨다.

## 바뀐 점 (04-R8a.md·05-R9.md 대비)

1. **R10a 없이 간다.** 렌더 엔드포인트는 포크 `utils/render_rgb_and_mask.py` 를 수정 없이 쓴다(0번 래퍼의 EXR 읽기 우회 포함, 5시점 렌더 후 요청 시점 1장만 반환). 구간 1 은 약 26 s 그대로다. R10a 는 나중에 이 자리에 끼운다 — 렌더 호출을 함수 하나(`render_condition(mesh, mask_cells, view)`)로 감싸 둔다.
2. **R4 를 쓴다(PR #18 미승인).** 브랜치 `item/04L-link-a5000` 은 `item/02-R4-a5000` 의 최신(경계 스냅 포함)에서 만든다. 워커는 `VHL_R4=1` 로 띄운다. 렌더 입력 메시: 판본에 텍스처 GLB 가 있으면(생성 판본) 그것, R4 판본이면 `.cbin` → 정점색 GLB(3-8 (iv) 보정).
3. **검증을 줄인다.** CLI 대비 14건 × 3회 비교는 하지 않는다. 대신:
   - 같은 입력 3회 연속(한 워커 프로세스): coords·보존 셀 비트 동일, 편집 셀은 E22 대로 한 프로세스 안이므로 비트 비교 결과를 적는다. 2·3회차 RSS·VRAM 복귀.
   - 트랙 A 6건 워커 1회 vs 동결 CLI(E2a c15 r1): coords·보존 셀 필수, 편집 셀 E14·E15(E21).
   - 거절 사유 §3.3 테스트, conformance 53/53, ai-ar-v3 서버 360 passed(A5000 `venv-tests`).
4. **종단(R-7)은 트랙 A 6건 × 3회.** 3090 에서 본 벽시계와 ①②③·전송 구간. `VHL_R9=1`. 조건 이미지는 동결본이 아니라 종단에서 새로 만든 것(INT4)이므로 결과는 R9 3D 기록으로 따로 적는다(품질 판정 아님, 기록).
5. **연결 확인을 먼저 한다.** 구현 전에 3090 → A5000:8082 TCP 연결을 시험한다(A5000 은 임시 리스너). 막혀 있으면 즉시 보고(방화벽은 고객사 관리자).
