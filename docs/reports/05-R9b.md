## 3. 오케스트레이터 동작 (`server/condrender.py`, 코드확인 + 모의 시험 실측)

```
VHL_R9=1:
  ① POST /v2/trellis/render {asset_id, base_version, mask, view}
     → render_id·두 해시. 응답 base_version ≠ 요청이면 중단. 파일 2장을 받아 해시 대조
  ② POST 127.0.0.1:INPAINT_PORT/inpaint?wait=1  image=2d_render, mask=2d_mask,
     prompt=spec.target_prompt(없으면 raw_prompt), seed=0
     → 2d_edit, 워커 보고 해시와 대조
  ③ POST /v2/trellis/edit multipart
     meta = 기존 본문 + render_id·render_sha256·mask_sha256, idempotency_key = 아래
     파트 2d_render · 2d_mask · 2d_edit
     RENDER_UNKNOWN → ①부터 1회. 두 번째도 그러면 보고
  ④ 이후(잡 폴링·청크·검증·저장)는 기존 코드 그대로
```

결정 반영:

| 규약 결정 (http-contract §4) | 반영 |
|---|---|
| 1. `RENDER_UNKNOWN` 이면 ①부터 1회 | 그대로. 다시 렌더한 두 해시가 처음과 **같으면 ②를 다시 돌리지 않고** 처음 `2d_edit` 를 쓴다 — INT4 는 같은 시드에서도 출력이 달라서(R9 실측), 다시 돌리면 오히려 조건이 바뀐다. 해시가 다르면 ②부터 다시 한다(둘 다 테스트) |
| 2. 기존 `image` 필드 바로 끊음 | 새 경로는 `image` 파트를 싣지 않는다(테스트). 옛 경로는 토글이 꺼졌을 때만 남는다 |
| 3. 멱등 키에 `sha256(2d_edit)` | 상류(③) 키 = `sha256(asset_id \| base_version \| raw_prompt \| mask 지문 \| seed \| sha256(2d_edit))[:16]`. Unity·라우트의 3090 잡 키는 3.15.5 그대로다(조건 해시를 안 주면 옛 식과 같은 값 — 테스트로 잠금) |
| 4. `view` 를 요청마다(0–4, 생략 0) | `EditRequest.view` 를 새로 받아 `BRenderRequest.view` 로 넘긴다. 범위 밖은 스키마가 거부한다 |

그 밖의 동작:
- **조건을 못 만들면 진행하지 않는다**(D40, 고객사 회신 A4). 워커 다운이나 인페인팅 실패면 ③을 보내지 않는다. t2i 경로로 떨어지지도 않는다(테스트).
- 상류 오류는 기존 규약대로 `UPSTREAM_<코드>` 로 보고한다. 예: `UPSTREAM_RENDER_MISMATCH`, `UPSTREAM_INPAINT_FAILED`.
- 구간 시간: 잡 `stage_detail` 에 "①렌더 x s ②인페인팅 y s ③제출 z s (렌더 n회)" 를 붙인다. `R9_TIMING_LOG` 를 주면 JSONL 로 남긴다(①·①파일·②·②워커 내부·③·업로드 바이트·재시도·재사용). 종단 계측(R-7 종단)에 쓴다.

### 테스트 13건이 잠그는 것

1. ①②③ 순서·각 1회. ③의 세 파트가 ①의 파일·②의 결과와 바이트 동일. `image` 파트 없음. meta 의 render_id·두 해시 일치. view·base_version 전달. ②의 프롬프트·시드 0·입력 해시
2. 상류 멱등 키 = 조건 해시 포함 식. 3.15.5 키와 다름
3. 조건 해시를 안 주면 키가 3.15.5 식 그대로
4. 타이밍 로그 필드
5. `RENDER_UNKNOWN` 1회 → 렌더 2회·편집 2회·인페인팅 1회(같은 렌더면 재사용)
6. 다시 렌더한 바이트가 다르면 인페인팅도 다시
7. `RENDER_UNKNOWN` 2회 → 보고, 렌더 2회에서 멈춤
8. `RENDER_MISMATCH` → 재시도 없이 보고
9. 다른 판본의 렌더 → 인페인팅 전에 중단
10. 워커 다운 → `UPSTREAM_UNREACHABLE`, ③ 안 보냄, t2i 안 부름
11. 워커 실패 → `UPSTREAM_INPAINT_FAILED`, ③ 안 보냄
12. **토글 기본 꺼짐 → 옛 t2i 경로**(렌더·인페인팅 호출 0)
13. 모의 서버가 §3.3 거절 사유(422·400·404·409·옛 JSON 422)와 정상 202 를 지킨다
