## 4. A5000 워커와 맞춰야 할 것 (종단 전, a5000 세션·chief)

1. **트랙 A 자산 id 와 base_version.** 오케스트레이터는 `asset_id`·`base_version` 으로 렌더·편집을 요청한다. A5000 워커가 쓰는 트랙 A 3자산(moto·snowman·chair)의 id 와 판본을 알려 주면 `--asset-map` 에 넣는다.
   - 형식: `{"moto": {"asset_id": "...", "base_version": n}, ...}`
2. **같은 base_version 으로 3회 반복.** 6건 × 3회는 매번 같은 부모 판본(W34 입력 = 동결 `slat_tgt`)에서 편집해야 비교가 된다. 그런데 R8a 지시서 A-1 은 "같은 자산은 판본 순서대로, 기준 판본이 다르면 409" 다. 편집이 판본을 하나씩 올리면 2회차부터 `VERSION_CONFLICT` 가 난다.
   - 길 하나: A5000 이 종단 시험용으로 같은 부모에서 갈라지는 판본을 허용한다.
   - 다른 길: 회차마다 판본을 되돌린다.
   - 정해지기 전에는 회차마다 다른 시나리오를 섞어도 같은 자산 두 편집(A-M1·A-M2 등)이 서로의 판본을 올린다.
3. **인증 키.** 워커가 `X-Blockedit-Key` 를 요구하면 그 값을 3090 `.env` 의 `A5000_KEY` 에 넣는다. 요구하지 않으면 비워 둔다.
4. **view.** 기본으로 동결 편집 시점을 보낸다. A5000 이 고르는 시점(`--view auto`)도 한 번 돌려 표로 남길지는 chief 가 정한다(R8a A-2 의 "선택 규칙 = 동결 시점?" 표와 같은 내용).
