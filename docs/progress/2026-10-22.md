## 6. 이슈와 위험

1. **동등성 여유:** 시드를 고정해도 같은 코드 2회의 편집 셀 차이가 3.30e-2 이다(0번, 1쌍). E7 로 분포 기준이 되었지만, 0-1 이식본이 같은 분포에 들어오는지는 GPU 비교 전까지 미검증이다.
2. **R9 품질:** INT4 가 2건에서 프롬프트를 따르지 못했다. 원인(장비·양자화·합성)은 분리 실험 전까지 미검증이다.
3. **INT4 비결정성:** 같은 시드에서도 결과가 매번 다르다. R9 판정은 반복 3회 분포로 한다.
4. **장비 간 전송:** 3090→A5000 직접 연결(SSH·8082)이 아직 없다. 지금은 git 전송 브랜치(`xfer/*`)로 넘긴다. 4번 R8a 에서 실연결이 필요하다.
5. **Edit3D-Bench 다운로드:** HF 요청 제한(5분 1,000회) 때문에 재시도하며 받는 중이다. 트랙 B 평가 지표 계산 전까지 끝나야 한다.
