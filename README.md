# paper-results 안내서 — 무엇을, 어떤 사진끼리, 무엇을 기준으로 보는가

VoxHammer-light 논문 실험(X-paper)의 캡처와 표다. 이 문서는 **사진을 어떻게 비교해 읽는지**를 설명한다. 렌더 설정·좌표 변환·원본 경로·sha256 같은 기술 기록은 [MANIFEST.md](MANIFEST.md)에, 수치 원값은 [tables/](tables/)에 있다.

- 경로 이름: **P0** = 원저자 VoxHammer 경로(편집마다 150시점 재등록 + 25 스텝 + `to_glb`). **P1** = 제안 경로(저장된 SLat 재사용 + 15 스텝 + R4 청크 출력 + 경계 봉합). **P2** = P1 에 매 편집 전 재등록만 더한 절제 경로.
- 모든 사진은 **같은 카메라·같은 조명·같은 렌더러·1024×1024·흰 배경**이다. 그래서 같은 자산의 사진끼리는 픽셀 위치가 그대로 대응한다. 나란히 놓고 같은 자리를 보면 된다.

---

## 0. 먼저 알아둘 것

### 사진 세 종류(모델 하나마다)

| 파일 | 무엇 | 언제 본다 |
|---|---|---|
| `shaded.png` | 고정 조명(스튜디오 HDRI) 렌더 | 전체 모양·보존 상태를 볼 때 |
| `albedo.png` | 조명 없이 표면 색만 | **색이 변했는지**를 볼 때. 조명·그림자 때문에 어두운 것과, 표면 색 자체가 어두워진 것을 가른다 |
| `crop.png` | 그 회차 편집 영역(3D 마스크 범위 + 여유 15%) 확대 | **편집이 프롬프트대로 됐는지** 볼 때 |

`original/r0/crop_r<k>.png` 는 원본에서 k회차 편집 영역을 잘라낸 것이다. 편집 전후를 같은 자리에서 비교할 때 쓴다.

### 시점

- 자산마다 카메라가 **하나**다(전 실험·전 경로·전 회차 공통). 캐릭터는 정면(고도 10°), 사물은 정면에서 45° 돌린 3/4 정면(고도 25°)이다. 오두막만 반대쪽으로 돌린 정면 −45° 다. 왼쪽 벽 창(2회차), 굴뚝(5회차), 정면 창 아래 꽃상자(3회차)가 한 사진에 다 보이게 하려고 정했다.
- 정면 방향과 분류는 [cameras.json](cameras.json)에, 확인용 한 장은 [sheets/view_check.png](sheets/view_check.png)에 있다.
- 시점이 하나라 편집 부위가 뒤쪽이면 보이지 않을 수 있다. X3 의 편집 15건은 모두 이 시점에서 편집 영역이 보인다(MANIFEST "편집 영역 가려짐").

### 시트(라벨 붙은 비교 격자)

개별 사진에는 글자가 없다. 비교하기 쉽도록 라벨을 붙인 격자는 [sheets/](sheets/)에 모았다. **처음에는 시트로 보고, 자세히 볼 때 폴더의 원본 사진을 연다.**

### 비교할 때 보는 기준(모든 실험 공통)

1. **보존:** 편집하지 않은 부분이 원본과 같은가. 모양(빠지거나 늘어난 부분), 색, 표면 결을 본다.
2. **편집:** 편집 영역이 프롬프트와 조건 이미지(`cond/…/2d_edit.png`)대로 바뀌었는가.
3. **누적(연속 편집·무편집 반복):** 회차가 지날수록 1·2번이 어떻게 변하는가.

## 1. X3 연속 5회 편집 — 논문의 핵심 비교

**질문:** 같은 자산을 다섯 번 이어서 편집할 때, 원저자 경로(P0)는 편집마다 다시 등록하면서 손실이 쌓인다. 제안 경로(P1)는 원본 표현을 유지하는가.

**대상:** 지프·오두막·모험가, 각 5회차. 각 경로는 자기 직전 결과에서 다음 회차를 편집한다. 원본 1장과 3경로 × 5회차.

| 자산 | 1회차 | 2회차 | 3회차 | 4회차 | 5회차 |
|---|---|---|---|---|---|
| 지프 | 앞 범퍼 → 크롬 불바 | 보닛 → 빨강 + 흰 줄 | 뒤 스페어 → 짐받이 + 연료통 | 지붕 → 짐받이 + 가방(추가) | 스노클 제거(원래 없음) |
| 오두막 | 현관문 → 아치형 빨간 문 | 왼쪽 벽 창 → 스테인드글라스 | 정면 창 아래 꽃상자(추가) | 현관 난간 → 흰 울타리 | 굴뚝 제거(**실패 사례**) |
| 모험가 | 모자 윗부분 → 마법사 모자 | 칼 → 등불 | 오른쪽 어깨 위 새(추가) | 부츠 → 빨간 운동화 | 방패 제거 |

### 어떻게 본다

1. **[sheets/x3_jeep_shaded.png](sheets/x3_jeep_shaded.png)** (오두막·모험가도 같은 이름 규칙)
   - 행은 원본, P0, P1, P2 이고, 열은 1–5회차다. 원본 행은 같은 사진이 다섯 번 반복된다.
   - **세로로 보면** 같은 회차에서 경로끼리 비교된다. **가로로 보면** 한 경로가 회차마다 어떻게 변하는지 보인다.
   - 보는 곳은 **편집하지 않은 부분**이다. 지프라면 문·바퀴·차체 옆면, 오두막이라면 지붕·벽판, 모험가라면 얼굴·옷이다.
     - P0: 회차마다 어두워지고 형태가 무너진다. 지프 5회차는 차체가 거의 검다.

2. **[sheets/x3_jeep_albedo.png](sheets/x3_jeep_albedo.png)** — 같은 격자를 조명 없이 찍은 것이다.
   - shaded 에서 어둡게 보인 것이 조명 탓이 아니라 **표면 색 자체가 어두워진 것**임을 확인한다. P0 albedo 가 실제로 검게 변한다.
3. **[sheets/x3_jeep_crop.png](sheets/x3_jeep_crop.png)** — 회차마다 편집 영역만 확대한 것이다.
   - 같은 열의 원본(편집 전)과 각 경로(편집 후)를 비교한다.
   - 편집 결과는 `x3/<자산>/cond/r<k>/<경로>/2d_edit.png`(그 경로가 3D 편집에 쓴 2D 목표 이미지)와 `prompt.txt` 와 비교한다. 경로마다 자기 직전 결과를 보고 2D 목표를 새로 만들었으므로 **2d_edit 도 경로마다 다르다.**
4. 논문 그림 후보: [img/X-paper-summary-x3-figure.png](img/X-paper-summary-x3-figure.png) — 3자산 × 1·3·5회차 × P0|P1|P2 한 장.

## 3. 청크 경계 봉합 — P1 의 작은 검은 점

**질문:** P1 은 바뀐 청크만 새로 보내고 나머지는 이전 것을 재사용한다. 그 경계에 생기는 작은 틈(검은 점)을 봉합 띠가 얼마나 없애는가.

**어떻게 본다**
- **[sheets/stitch_jeep_p1_variants.png](sheets/stitch_jeep_p1_variants.png)** — 지프 P1, 행은 다섯 가지 메시이고 열은 1–5회차다.

  - `p1_stitch(x3)`: 봉합(채택안 = X3 의 P1)
  - `p1_skirt`: 치마 벽(시험)
  - `p1_stitch_skirt`: 봉합 + 치마(시험)
  - `p1_fulldecode`: 재사용 없이 통째로 디코딩한 것 = **틈이 없어야 하는 기준**
- **보는 곳:** 차체 문·펜더·앞유리 테두리의 아주 작은 검은 점이다. 원본 사진 `stitch/jeep/<변형>/r<k>/shaded.png` 를 확대해서 본다.

- P2 와 다른 자산의 봉합 전 메시는 `stitch/<자산>/{p1,p2}_prestitch/` 에 있다. 같은 회차의 `x3/<자산>/{p1,p2}/r<k>/`(봉합본)와 비교한다.

## 7. X2-B Edit3D-Bench 3건 — 공개 벤치마크 예시

## 8. 사람 평가(X3)

**무엇:** X3 15개 항목(자산 × 회차)마다 P0·P1·P2 결과를 A·B·C 칸에 무작위 순서로 놓고 경로 이름을 가렸다. 평가자는 항목마다 "보존 상태가 가장 좋은 것"과 "편집이 프롬프트대로 된 것"을 하나씩 골랐다.

## 9. 실루엣 확인 시트 읽는 법

`sheets/silhouette_<실험>_<자산>_<경로>_r1.png` 는 원본과 그 경로 1회차의 윤곽을 겹친 것이다.

| 색 | 뜻 |
|---|---|
| 회색 | 둘 다 있음(겹침) |
| 빨강 | 원본에만 있음(결과에서 사라짐) |
| 파랑 | 결과에만 있음(새로 생김) |

- 목적은 **같은 시점에서 찍혔는지** 확인하는 것이다. 시점이 어긋나면 윤곽 전체가 한쪽으로 밀린 빨강·파랑 띠가 생긴다.
- 편집 부위에만 빨강·파랑이 있으면 정상이다(편집이 모양을 바꾼 것).
- 74쌍 모두 시점 어긋남은 없었다. 편집 영역을 빼고 잰 겹침이 최소 0.916 이다(MANIFEST).

## 10. 볼 때 주의할 점

- **회차마다 비교 영역이 다르다(X3 표).** 표의 보존 지표는 그 회차까지 편집한 영역을 뺀 나머지에서 쟀다. 회차가 지날수록 비교 영역이 줄어든다. 사진은 항상 전체를 찍었다.
- **P1·P2 색은 정점색이다.** 텍스처가 아니라 메시 정점마다 색이 있다. 아주 가까이 보면 P0(텍스처)보다 색이 부드럽게 번져 보일 수 있다. 렌더 전에 색 공간 보정을 했다(MANIFEST).
- **재질은 셋 다 같다.** glTF 기본(금속성 1.0)이다. 경로 사이의 밝기 차이는 재질 차이가 아니라 표면 색 차이다(albedo 로 확인).
- **X4 P0 좌표.** 회차마다 생기는 재정규화 표류는 되돌리지 않았다(채점과 같음). 실루엣 겹침은 0.96 이상이라 비교에는 영향이 작다.
- **단발 실행.** X3·X2-B 는 경로마다 1회다. 칸 하나하나는 표본 1개다.
- **같은 출처를 여러 폴더에 둔 경우.** X0 의 15 스텝 r1 과 X2-A 의 P1 r1 은 같은 출력이다. 표본을 이중으로 세지 않도록 주의한다.
